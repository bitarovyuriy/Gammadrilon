# Gammadrilon 3.5

Локальная утилита для Windows: гамма монитора и подсветка через DDC/CI, профили питания CPU и GPU, обход DPI (zapret), DNS, датчики температуры без прав администратора.

## Что нового

**Работает на чужом ПК**

- Установщик без прав администратора: ставится в профиль пользователя (`%LOCALAPPDATA%\Programs`), UAC не спрашивает пароль.
- Данные и настройки — в `%LOCALAPPDATA%\Gammadrilon`; рядом с exe можно включить портативный режим одной кнопкой.
- Первый запуск предлагает тему и автозапуск и сразу проверяет окружение.
- Проверка обновления идёт через системный прокси, если прямой маршрут недоступен.
- Если `presets.json` повреждён, настройки восстанавливаются из последней целой копии, а битый файл остаётся рядом как `.bak`.

**Диагностика вместо «не работает»**

- Вкладка «Диагностика»: 14 проверок (права, пути, Qt-плагины, видеокарта, датчики, .NET, zapret, прокси, UAC, монитор, размер конфига) с человеческими подсказками.
- Архив для поддержки: один zip с отчётом и хвостами журналов.
- `Gammadrilon.exe --selftest` — те же проверки без окна, код возврата 1 при провале.

**Экран**

- Гамма: RGB, контраст, яркость, насыщенность и тени (Shadow Boost) отдельными пресетами.
- Подсветка монитора через DDC/CI с фоновым зондом; если монитор не умеет — честно выключено, а не ползунок в пустоту.
- Частота обновления: меняется только герцовка, разрешение и масштабирование не трогаются.
- Автопрофиль по игре: при запуске `cs2.exe` включается нужный пресет, при выходе возвращается прежний.
- Плитка на главном показывает, что применено: пресет, подсветка, частота.

**Система**

- Профили питания CPU и лимита мощности GPU, в том числе через отдельный компаньон с правами администратора — запрос UAC один раз.
- Телеметрия NVML вместо `nvidia-smi`: 25 мс против 76 мс.
- Игровой буст: сжатие рабочих наборов фоновых процессов, EcoQoS, таймер 0,5 мс; защита от античитов.
- Обход DPI: разбор `general.bat`, перебор стратегий с проверкой TLS, кэш удачной. Живой `winws.exe` без явного разрешения не останавливается.
- Откат временных изменений при выходе и при завершении сеанса Windows.

## Установка

1. `Gammadrilon-Setup-3.5.exe` — установка в профиль, без администратора.
2. Или распаковать `Gammadrilon-v3.5-portable.zip` и запустить `Gammadrilon.exe`.

Требования: Windows 10/11 x64, права пользователя. Для датчиков температуры — .NET Framework 4.8 (есть в системе по умолчанию с Windows 10 1903).

zapret, WinDivert и драйвер PawnIO в установщик **намеренно не входят**: антивирусы считают их нежелательными, а обход DPI — отдельное решение пользователя.
