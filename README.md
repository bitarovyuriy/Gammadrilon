## О проекте

**Gammadrilon** — локальное приложение для Windows: экран и питание системы в одном окне, без облака и телеметрии. Гамма, яркость, контраст и цветовая температура меняются через Windows Gamma API, питание CPU — через `powrprof`, питание GPU — через `nvidia-smi`. Операции, которым нужны права администратора (лимит GPU, очистка ОЗУ, DNS, обход DPI), выполняет отдельный elevated-компаньон — один запрос UAC на всё; если прав нет, приложение прямо скажет «нужны права администратора», а не сделает вид, что сработало.

## Возможности

**Главный экран** — свой пульт из плиток, приложение открывается сразу на нём: состав, порядок и ширину виджетов задаёшь сам в режиме «Правка», раскладка переживает перезапуск. Плитка показывает живые данные (CPU, GPU, ОЗУ, питание, DNS, гамма) и по клику ведёт в свою вкладку. Плитка «Обход DPI» управляет обходом прямо с пульта: тумблер вкл/выкл, выбор стратегии, GameFilter TCP и UDP, IPSet.

**Экран** — гамма, яркость, контраст, цветовая температура; пресеты, глобальные горячие клавиши, плавные переходы, режим трея.

**Питание CPU** — профили (эко / обычный / разгон) через `powrprof`, расширенные параметры, живые сенсоры (частота, нагрузка, температура ядра, температура VRM), откат при выходе и сторожевой таймер компаньона: если окно упало, настройки возвращаются сами. Переключатель «ограничение ↔ производительность» одной клавишей (по умолчанию `Ctrl+Alt+P`, есть и в трее с палитрой), со своим звуком на каждое состояние: глухой уходящий вниз — ограничения включились, звонкий идущий вверх — снялись. Пару профилей и звук настраивают в «Глобальных клавишах», там же оба звука можно послушать.

**Температуры** — отдельным хелпером на LibreHardwareMonitor: ядро (Tctl/Tdie у AMD, Package у Intel) и каналы платы через Super I/O. Хелпер поднимается один раз с повышением прав и уходит вместе с окном; если драйвера нет — плитка честно показывает «—», остальное приложение работает как обычно. Нужен драйвер [PawnIO](https://pawnio.eu) (подписан, совместим с Memory Integrity) — приложение его не ставит и не подменяет. VRM у бюджетных плат безымянный: в BIOS-профиле датчика нет имени, поэтому канал VRM выбирается вручную в `presets.json` (`sensors_vrm_channel`), по умолчанию выключен.

**Питание GPU** — профили и лимит мощности (NVIDIA); применённый лимит держится до кнопки «Вернуть как было» или до закрытия приложения, автолимит при запуске возвращает выбранное значение.

**ОЗУ** — очистка standby-списка и сжатие рабочих наборов выбранных процессов, автоочистка по порогам, честные значения «до / после».

**DNS** — замер латентности реальными DNS-запросами, смена резолвера из списка, сохранение текущей конфигурации перед сменой (кнопка «Вернуть как было»), DoH (Windows 11), сброс кэша.

**Обход DPI (zapret)** — выбор стратегии, тумблеры GameFilter TCP/UDP (с диапазонами портов) и IPSet, проверка доступности Discord/YouTube, статус и журнал `winws.exe`; проверка и установка релизов Flowseal прямо из окна, обновление `ipset` и `hosts`, установка и обслуживание службы автозапуска без консольного `service.bat`; запущенный приложением обход останавливается при выходе, чужой `winws.exe` не трогается никогда.

**Правила** — триггеры «запуск процесса», «переход на батарею» и «по расписанию», условия (загрузка, питание, процессы) и действия, журнал срабатываний. Расписание срабатывает, когда указанное время наступает при работающем приложении; пропущенное время не «догоняется».

**Интерфейс** — монохромный «Пульт» (сайдбар, свой титлбар — окно тянется мышью за шапку, двойной клик по ней разворачивает, статусбар с живыми метриками CPU / GPU / RAM / DNS), светлая и тёмная тема, палитра команд, журнал изменений, тосты, масштаб 100 / 125 / 150 %, фокус-ринги и обход по Tab. Окно всегда открывается на главном экране; палитра ищет и по настройкам — команда «Настройки: …» открывает нужную вкладку и ставит курсор в поле (яркость, лимит GPU, DNS и т.д.); из журнала копируется и строка записи, и путь к файлу.

**Локализация** — русский и английский, переключается в настройках; при первом запуске — по системной локали.

**Перенос настроек и обновления** — настройки приложения, пресеты гаммы, правила, «тихий час» и автоочистка переносятся одним JSON-файлом («Утилиты» → экспорт/импорт; перед импортом прежний конфиг сохраняется рядом как `presets.before-import.json`). Проверка обновлений по GitHub Releases — по галочке и по умолчанию выключена: без неё проверка обновлений в сеть не ходит, а с ней уходит только сам запрос (ни версии, ни идентификаторов), причём при запуске — не чаще раза в сутки (кнопка «Проверить сейчас» ходит всегда). Если релиз новее, в «Утилитах» появляется кнопка «Скачать и обновить»: приложение скачивает `Gammadrilon-portable.zip` (или новый exe), проверяет sha256 из GitHub, перезапускается через helper и заменяет только exe и `_internal`. `presets.json` и остальные данные остаются на месте; перед обновлением рядом сохраняется `presets.before-update.json`, при неудачном старте helper откатывает файлы. Автообновление работает только в собранной версии; подписи у exe нет, поэтому защита — HTTPS, фиксированные имена ассетов и sha256. Остальные сетевые функции (DNS-замеры, обход DPI) работают независимо от этой галочки.

**Стоп-кран** — `Ctrl+Alt+R` (меняется в «Глобальных клавишах», есть и в трее, и в палитре) после одного подтверждения возвращает всё как было: питание CPU/GPU, DNS, правила, автоочистку, точность системного таймера и гамму.

**Портативный режим** — положите рядом с `Gammadrilon.exe` файл `portable.txt`: журнал, правила, state-файлы и логи начнут писаться в ту же папку, и её можно унести на флешке целиком. Без маркера всё как обычно: данные — в `%ProgramData%\Gammadrilon`, логи — в `%LocalAppData%\Gammadrilon`. Где лежат данные сейчас, написано в «Утилитах» рядом с экспортом и импортом.

**Локальный API для инструментов** — белый список действий (чтение: `status`, `sensors`, `journal`, `rules`, `zapret`; изменение: профили CPU/GPU, лимит GPU, DNS), подтверждение каждого изменения в окне, автоотклонение через 60 секунд, аудит в `agent_audit.jsonl`. По умолчанию выключен.

## Требования

- Windows 10/11 (x64).
- Для вкладки «Питание GPU» — видеокарта NVIDIA (`nvidia-smi` из состава драйвера).
- Для температур CPU и платы — драйвер PawnIO (ставится один раз, приложение его не ставит).
- Часть операций требует прав администратора: приложение запрашивает их через отдельный компаньон (один запрос UAC) и честно сообщает об отказе, если прав нет.
- Запуск из исходников: Python 3.10+ (проверено на 3.14.7) и `pip install -r requirements.txt` (PyQt5, keyboard, psutil).
- Путь к исходникам — **без кириллицы**: PyQt5 5.15.11 на Windows иначе не находит Qt-плагины
  (`Could not find the Qt platform plugin "windows"`). Сборка из такого пути тоже падает.

## Запуск из исходников

```
pip install -r requirements.txt
python main.py
```

## Проверки

Инструменты разработки — в `requirements-dev.txt` (pytest, ruff, PyInstaller), версии зафиксированы.

```
pip install -r requirements-dev.txt

.venv\Scripts\ruff.exe check .        # линтер: мёртвый импорт, опечатки, синтаксис
.venv\Scripts\python.exe -m pytest    # быстрые проверки договорённостей: версия, переводы, spec, сборка
$env:GD_SMOKE=1; .venv\Scripts\python.exe -m pytest tests\test_smoke.py   # полная смоук-проверка окна
```

Смоук `tests\smoke_check.py` поднимает окно в offscreen-режиме и проверяет фут,
темп метрик, DNS, трей, правила и GPU. Он не пишет в `presets.json`, не применяет
профили и не поднимает компаньонов; отчёт — `build/shots/verify.log`, при провале
код возврата 1. Тот же CI гоняет на каждый пуш: линтер и `pytest` (смоук — по кнопке).

## Сборка

- `Gammadrilon.spec` — портативная сборка в папку: `dist/Gammadrilon/`
- `Gammadrilon-onefile.spec` — один файл: `dist/Gammadrilon.exe`
- список модулей в спецификации собирается сам из `gd_*.py`: новый модуль не нужно вписывать руками
- `build_release.ps1` — собирает оба варианта, пакует zip через `tar.exe` и печатает хэши sha256 для текста релиза
- порядок релиза — в `RELEASE_CHECKLIST.md`
- UPX выключен: упаковка Qt-DLL даёт ложные срабатывания антивирусов и лишние предупреждения SmartScreen
- Собирать нужно из пути **без кириллицы**: PyInstaller 6.22 не находит Qt-плагины,
  если в пути есть не-ASCII символы (`Qt plugin directory 'D:/?laude/...' does not exist`).
- Zip лучше паковать `tar.exe -a -c -f <zip> -C dist <папка>`: `Compress-Archive` падает,
  если свежескопированный файл на секунду придержал антивирус или индексатор (`build_release.ps1` делает именно так).
- Отладочные пробы автора (`_tmp_*.py` в корне) в репозиторий не попадают — они в `.gitignore`.
