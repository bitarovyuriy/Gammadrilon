# Gammadrilon Lite

Отдельная версия для Windows x64 на базе тега `v3.6.6`. Полная версия остаётся в `main`.

1. Скачай `Gammadrilon-Lite-v…-portable.zip` со страницы [GitHub Releases](https://github.com/bitarovyuriy/Gammadrilon/releases) и распакуй **целиком**.
2. Запусти `GammadrilonLite.exe` из получившейся папки. Установщик и отдельный Python не нужны.

Перед запуском сверяй SHA-256 архива с `SHA256SUMS.txt`. Для функций с UAC держи распакованную копию в локальной папке, недоступной на запись другим пользователям. Не запускай её из общей сетевой папки.

| Раздел | Что делает |
| --- | --- |
| Яркость | Ползунок для основного экрана и переключение 65 / 100 % кнопкой или `Ctrl+Alt+B`. Это программная яркость, не подсветка. При обычном выходе исходная гамма возвращается, если её не поменяло другое приложение. HDR и некоторые драйверы могут не принять изменение. |
| CPU | Эко / Обычный / Буст и «Вернуть» для восстановления исходной схемы. `Ctrl+Alt+P` переключает Эко и Буст. Lite меняет собственную копию схемы, помеченную `GD Lite`. |
| GPU | Тихий / По умолчанию / Игровой / Максимум. Только лимит мощности NVIDIA через NVML, если модель и драйвер его поддерживают. |
| DNS | Готовые IPv4-провайдеры для адаптера маршрута по умолчанию. «Вернуть» восстанавливает исходные настройки, сохранённые Lite. |
| zapret | Включение и выключение установленной службы `zapret`; выбор совместимой стратегии из её каталога, отдельные TCP и UDP с диапазонами портов, режим IPSet. Работающая служба перезапускается после применения; при ошибке Lite пытается вернуть прежние настройки. Lite не устанавливает службу и не выполняет BAT-файлы. |
| Температуры | GPU NVIDIA обновляется раз в 5 секунд на открытой вкладке «Пульт». CPU берётся из свежего замера полной версии, если он доступен, либо снимается кнопкой «Замер CPU». Ручному замеру может понадобиться UAC и уже установленный PawnIO. Помощник ничего не устанавливает. |

Горячие клавиши работают и в свёрнутом окне, если сочетания не заняты другой программой. При сворачивании опрос датчиков выключен. Питание, DNS и состояние службы после закрытия сохраняются по правилам Windows и драйвера; чтобы откатить, используй соответствующее действие. Для системных изменений Windows может запросить права администратора; помощник завершает работу после команды. Папка отката CPU/DNS: `%LOCALAPPDATA%\GammadrilonLite`. Не удаляй её до восстановления исходных настроек. Не управляй одними и теми же системными настройками из обеих версий одновременно.

Нет PyQt, графиков, постоянного процесса датчиков, игровых модулей, очистки памяти, правил, трея, автозапуска и автообновления. Крестик закрывает программу.

## Из исходников

На Windows с Python 3.12+ и Tcl/Tk: `python main.py`. Зависимостей приложения из pip нет. Тесты и упаковка: `python -m pip install -r requirements-dev.txt`, `python -m pytest`, `python build_lite.py`. Сборка использует Windows-компилятор .NET Framework для разового замерщика CPU. Готовый архив в `dist/monochrome`. `--smoke` проверяет окно с отключённым опросом; `--diagnose` проверяет импорт обработчиков без изменения настроек.
