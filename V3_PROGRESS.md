      («нужны права администратора (STATUS_PRIVILEGE_NOT_HELD)»), не тихий no-op.
      Автоочистка по порогам (дефолт 1024/1024 МБ, выключена), подпись про кэш

- [x] `gd_dns.py` + `gd_dns_ui.py` — вкладка «DNS»: замер латентности **реальными

      медиана + разброс + потери; смена только из явного списка (Cloudflare, Google,

      (`DnsFlushResolverCache` + `ipconfig /flushdns`); обязательная подпись.
      Смена DNS и DoH требуют прав администратора → через elevated-хелпер.

## Грабли (для будущих этапов)

- Из терминала Hermes: `env -u PYTHONPATH` при работе с проектным venv — Hermes
  протаскивает свой PYTHONPATH, pip видит чужие пакеты («already satisfied»).
- QT_PLUGIN_PATH-фикс обязателен в каждом исполняемом скрипте с PyQt5 (кириллица
  в пути), и ставить его до первого импорта PyQt5.

  недоступен (WinError 5, ACL). Связь UI ↔ elevated-хелпер — loopback TCP 127.0.0.1
  со встроенным handshake `authkey` из multiprocessing.connection.
