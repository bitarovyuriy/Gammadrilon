# Gammadrilon 3.6.6

## Оптимизация CS2

В новых профилях мягкий режим по умолчанию включает игровой режим Windows. В ранее настроенных профилях используется выбор пользователя. Страница подсказывает, как сравнить время кадра, FPS и пропуски тиков по телеметрии CS2. Эффект настроек зависит от компьютера и фоновой нагрузки.

При включении Gammadrilon сохраняет исходные значения только для настроек, которые меняет. Откат сохраняет изменения, внесённые пользователем или другой программой после включения. Если прежняя схема питания удалена, остальные настройки можно восстановить, а текущую схему оставить после явного подтверждения.

## Исправления

- **Игровой буст.** Восстановление проверяет время создания процесса и пропускает запись, если исходный процесс нельзя подтвердить. После частичного отказа остаются только параметры, которые ещё нужно восстановить.
- **Bufferbloat.** В замер под нагрузкой входят только пробы, во время которых поступали данные. При срыве загрузки или недостаточном замере приложение объясняет, почему оценка не рассчитана.
- **TLS.** Портативная и однофайловая сборки включают список исключённых центров сертификации среды сборки, когда Python использует такой список. Самопроверка проверяет создание TLS-контекста с системным доверием.

## Файлы выпуска

- `Gammadrilon-Setup-3.6.6.exe` — установщик Windows x64.
- `Gammadrilon.exe` — однофайловая сборка.
- `Gammadrilon-portable.zip` — портативная папка. Распакуйте архив перед запуском.
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

## Границы проверки

Применение и откат настроек проверялись с подменой системных записей. Эффект для FPS и задержки в матче требует замеров в реальной игре. Проверка TLS создаёт контекст без сетевого запроса. Чистая установка, удаление и обновление установленной копии требуют отдельного прогона на Windows.
