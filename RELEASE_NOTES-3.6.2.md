# Gammadrilon 3.6.2

Обновление про порядок в «Утилитах» и про горячие клавиши, которые теперь можно снять.

## Что нового

**Утилиты разложены по разделам**

- Вместо одной длинной простыни — пять разделов: **Память**, **Система**, **Игры**, **Правила**, **Клавиши**. Каждый открывается по клику, тяжёлые собираются при первом заходе, поэтому вкладка открывается сразу.
- **Очистка ОЗУ и игровой буст** — в одной карточке «Память»: сначала цифры, потом кнопки очистки, ниже буст. Раньше это были два блока, между которыми приходилось бегать.
- **Оптимизация CS2** и **Правила** переехали внутрь «Утилит» — отдельных пунктов в сайдбаре больше нет. Плитки главного экрана, палитра команд и трей ведут в те же разделы, так что привычные пути работают.

**Горячие клавиши можно назначить и снять**

- Новый раздел «Клавиши»: таблица действий, поле сочетания и кнопка **«Убрать»**. Пустое поле — законное «не назначено»: клавиша возвращается системе.
- Проверка до сохранения: непонятное сочетание и повтор двух действий в одном поле не пройдут, в статусе будет причина.
- «Вернуть умолчания» восстанавливает заводские сочетания, «Сохранить и применить» перерегистрирует их без перезапуска.

**Подсказки больше не занимают экран**

- Длинные пояснения у карточек убраны в значок **«i»** — читаются по наведению, а не висят под каждым блоком.
- Текст, который раньше обрезался в шапке «Утилит», перенесён внутрь карточки памяти.

**Запуск с правами администратора**

- В карточке автозапуска новая галочка **«Запускать с правами администратора»**, включена по умолчанию: без прав лимит GPU, DNS и очистка ОЗУ каждый раз просят UAC.
- Способ применяется сразу: файл автозагрузки переписывается, отдельный перезапуск не нужен. Галочка действует только вместе с автозапуском.

**Автообновление**

- Исправлено: установщик `Gammadrilon-Setup-*.exe` больше не может быть выбран как «новая версия программы». Раньше обновление однофайловой сборки могло подменить приложение установщиком.
- Ассеты выбираются по назначению: программе — exe, портативной сборке — zip.

**Запуск и диагностика**

- Если Qt не находит платформенный плагин, вместо системного диалога показывается окно с причиной и тем, что установить (при запуске без консоли текст раньше просто терялся).
- Пути к плагинам Qt выставляются всегда, а не только на путях с кириллицей: чужой интерпретатор с ASCII-путём теперь тоже находит `qwindows.dll`.
- Каждый запуск пишет строку в `qt_boot.log` (интерпретатор, папка пакетов, найден ли `qwindows.dll`) — по ней разбирается любой будущий сбой запуска.

## Установка

- Установщик: `Gammadrilon-Setup-3.6.2.exe`, ставится без прав администратора в `%LOCALAPPDATA%\Programs\Gammadrilon`.
- Портативная сборка: `Gammadrilon-v3.6.2-portable.zip` — распаковать и запустить `Gammadrilon.exe`.
- Настройки и журналы: `%LOCALAPPDATA%\Gammadrilon`. Портативный режим хранит их рядом с программой.
