# Чеклист релиза

Короткий список того, что легко забыть в день релиза. Проверки ниже уже
автоматизированы — здесь только порядок и то, что делается руками.

## До сборки

- [ ] номер версии в `APP_VERSION` (`main.py`) — единственное место с версией;
      вписать «v3.x» где-то ещё (в том числе в README, чеклисте, spec, CI или
      `build_release.ps1`) не даст `pytest` — тест `test_version_has_single_source`
- [ ] `V3_PROGRESS.md` дописан: что вошло, что осознанно не вошло и почему
- [ ] `ruff check .` — чисто
- [ ] `python -m pytest` — чисто (версия, переводы, spec, способ упаковки zip)
- [ ] `$env:GD_SMOKE=1; python -m pytest tests/test_smoke.py` — окно живо (offscreen):
      заодно проверяются стоп-кран в диалоге клавиш и палитре, поиск по настройкам,
      копирование из журнала
- [ ] `python tools/pages_check.py` и `python tools/pages_check.py --lang en` —
      10 вкладок на пустом профиле, ни одна не падает (RU и EN)
- [ ] `python tools/visual_check.py --theme light --suffix @light` — светлая тема не разъехалась
- [ ] `python tools/a11y_check.py` — у всех кнопок и списков есть имя, все доступны с Tab
- [ ] `python tools/lang_check.py` — смена языка RU→EN→RU на живом окне без падений
- [ ] `python tools/visual_check.py` — 5 стабильных страниц совпали с эталоном
      (менялась вёрстка — `--update` и глазами сравнить `build/shots/baseline`
      с `build/shots/current`)
- [ ] `python tools/soak_check.py --minutes 6` — память не растёт без переключений;
      при переключении рост только от кэша Qt («рост есть, но медленный»)
- [ ] `settings.last_boot_ms` в диагностике меньше 3 с на этой машине (иначе —
      виноват антивирус или диск, а не код)
- [ ] рабочее дерево закоммичено: релиз собирается из коммита, а не из `git stash`

## Сборка

- [ ] собирать из пути **без кириллицы** (например, `C:\gd_build`): не-ASCII символы
      ломают поиск Qt-плагинов и у PyInstaller, и у PyQt5 при запуске из исходников
- [ ] `build_release.ps1` → `dist/Gammadrilon.exe` и `dist/Gammadrilon-portable.zip`
      (скрипт печатает sha256 обоих файлов — они нужны в тексте релиза)
- [ ] `build_release.ps1` сам гоняет `Gammadrilon.exe --selftest` перед упаковкой:
      «провалов: 0 из 15» и код 0; иначе релиз останавливается (таймаут 90 с)
- [ ] `tools/release_check.ps1` — тихая установка → `--selftest` установленного exe →
      удаление, все шаги зелёные (проверяет установщик, а не только сборку)
- [ ] оба артефакта запущены руками: релизный exe и exe из портативной папки
- [ ] портативный режим с маркером: положить рядом с exe файл `portable.txt`,
      запустить — в папке появляются `journal.jsonl`, `rules.json`, `dns_state.json`,
      `gammadrilon.log`; убрать маркер — данные снова читаются из
      `%ProgramData%\Gammadrilon` (в «Утилитах» рядом с экспортом написано, где
      лежат данные и что включает режим)
- [ ] стоп-кран: `ctrl+alt+r` показывает подтверждение, согласие возвращает питание
      CPU/GPU, DNS, правила, автоочистку, таймер и гамму
- [ ] питание CPU: применить один профиль дважды — в системе остаётся **одна** наша
      копия схемы (повторное применение пишет в неё, а не создаёт новый клон), имя без
      повторяющихся меток «Gammadrilon — »; после ручного выбора другой схемы статус
      честно говорит «наша копия без профиля», а не «исходная схема»
- [ ] стартовый экран: закрыть приложение на любой вкладке, открыть — всегда
      «Главный» (прежняя вкладка не восстанавливается намеренно)
- [ ] температуры: на машине с драйвером PawnIO плитка «Процессор» и статусбар показывают
  °C, без драйвера — «—» и ничего не падает (хелпер `GammadrilonSensors.exe` лежит в
  `_internal/vendor/lhm`, поднимается один раз и уходит вместе с окном)
- [ ] проверка «без прав»: на учётке без администратора приложение должно честно
      сказать «нужны права администратора», а не сделать вид, что сработало
- [ ] проверка «не пусто»: в портативной папке лежат `icon.ico`, `README.md`, `LICENSE`
- [ ] автопрофиль по игре: добавить правило на `notepad.exe`, переключиться на блокнот —
      пресет сменился; вернуться на рабочий стол — пресет вернулся (и в конфиг не записался)
- [ ] подсветка монитора: ползунок двигает яркость матрицы, а на мониторе без DDC/CI
      он честно выключен с подписью «не поддерживает»
- [ ] перебор стратегий zapret: при **запущенном** обходе кнопка отказывает
      («остановите его перед подбором»), а не убивает рабочий `winws.exe`

## Публикация

- [ ] тег на коммите сборки: `git tag v3.x && git push --tags` — тег тем же номером,
      что `APP_VERSION` в `main.py` (иначе «Установлена последняя версия» соврёт)
- [ ] в тексте релиза: sha256 обоих артефактов из вывода `build_release.ps1`
- [ ] в тексте релиза: изменения словами пользователя («что теперь можно»), а не
      списком коммитов
- [ ] после публикации: скачать `Gammadrilon.exe` из релиза и запустить — то, что
      скачал пользователь, должно запускаться (SmartScreen может ругаться: подписи нет)
