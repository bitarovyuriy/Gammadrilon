# Чеклист релиза

Короткий список того, что легко забыть в день релиза. Проверки ниже уже
автоматизированы — здесь только порядок и то, что делается руками.

## До сборки

- [ ] номер версии в `APP_VERSION` (`main.py`) — единственное место с версией;
      вписать «v3.x» куда-то ещё не даст `pytest` (тест `test_version_has_single_source`)
- [ ] `V3_PROGRESS.md` дописан: что вошло, что осознанно не вошло и почему
- [ ] `ruff check .` — чисто
- [ ] `python -m pytest` — чисто (версия, переводы, spec, способ упаковки zip)
- [ ] `$env:GD_SMOKE=1; python -m pytest tests/test_smoke.py` — окно живо (offscreen)
- [ ] рабочее дерево закоммичено: релиз собирается из коммита, а не из `git stash`

## Сборка

- [ ] собирать из пути **без не-ASCII**: `D:/?laude/...` ломает поиск Qt-плагинов
- [ ] `build_release.ps1` → `dist/Gammadrilon.exe` и `dist/Gammadrilon-portable.zip`
      (скрипт печатает sha256 обоих файлов — они нужны в тексте релиза)
- [ ] оба артефакта запущены руками: релизный exe и exe из портативной папки
- [ ] проверка «без прав»: на учётке без администратора приложение должно честно
      сказать «нужны права администратора», а не сделать вид, что сработало
- [ ] проверка «не пусто»: в портативной папке лежат `icon.ico`, `README.md`, `LICENSE`

## Публикация

- [ ] тег на коммите сборки: `git tag v3.x && git push --tags`
- [ ] в тексте релиза: sha256 обоих артефактов из вывода `build_release.ps1`
- [ ] в тексте релиза: изменения словами пользователя («что теперь можно»), а не
      списком коммитов
- [ ] после публикации: скачать `Gammadrilon.exe` из релиза и запустить — то, что
      скачал пользователь, должно запускаться (SmartScreen может ругаться: подписи нет)
