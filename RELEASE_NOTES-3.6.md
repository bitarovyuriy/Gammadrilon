# Gammadrilon 3.6

Локальная утилита для Windows: гамма монитора и подсветка через DDC/CI, профили питания CPU и GPU, обход DPI (zapret), DNS, датчики температуры без прав администратора.

## Что нового

**Скорость**

- Первое окно появляется в 7 раз быстрее: запуск хелпера температур больше не держит старт (3,3 с → 0,5 с). В диагностике видно «Время старта» прошлого запуска.

**Честный запуск и сохранение**

- Если запустить исходники чужим Python без PyQt5, вместо системного диалога Qt печатается инструкция, что поставить, и код выхода 2.
- Окно помнит размер и развёрнутость между запусками (и не переносит их на другую машину).
- Автозапуск приводится к настройке при каждом старте: лишний файл в «Автозагрузке» убирается, устаревший путь переписывается на текущий.
- Повреждённый `presets.json` восстанавливается из последней целой копии, битый остаётся рядом как `.bak`.
- Настройки не теряются молча: если папка недоступна для записи, окно говорит об этом, а не делает вид, что сохранило.

**Экран**

- Подсветка при двух мониторах: выбор монитора (только те, что умеют DDC/CI), выбор запоминается.
- Тени (Shadow Boost) в пресетах, частота обновления меняется без сброса разрешения.
- Главный экран показывает, что применено: пресет · подсветка · частота, и что ещё не настроено — с переходом на нужную вкладку.

**Диагностика**

- 15 проверок, включая размер конфига и время старта; архив для поддержки; `--selftest` без окна.
- Метаданные версии у exe и установщика — «Свойства → Подробно» больше не пустые.

**Перенос и обновление**

- Портативный режим одной кнопкой и «чемоданчик» — папка с настройками для другого ПК.
- Обновление показывает «Что нового» до подтверждения и проверяет sha256 скачанного файла.
- Установщик легче на 1,3 МБ: из сборки убраны неиспользуемые Qt5Qml/Qt5Quick.

**Надёжность**

- 347 автотестов: страницы на пустом профиле (RU/EN/без датчиков), смена языка и темы, доступность с клавиатуры, контраст WCAG AA, визуальная регрессия на 100/125/150/200 % в обеих темах, переводы и вызовы `i18n.t`, устойчивость к обрыву хелпера и битым файлам.
- Проверено: установка в путь с кириллицей и пробелом, обновление поверх старой версии, аварийное завершение, конфиг только для чтения.

## Установка

1. `Gammadrilon-Setup-3.6.exe` — установка в профиль, без администратора.
2. Или распаковать `Gammadrilon-v3.6-portable.zip` и запустить `Gammadrilon.exe`.

Требования: Windows 10/11 x64, права пользователя. Для датчиков температуры — .NET Framework 4.8 (есть в системе по умолчанию с Windows 10 1903).

zapret, WinDivert и драйвер PawnIO в установщик **намеренно не входят**: антивирусы считают их нежелательными, а обход DPI — отдельное решение пользователя.
