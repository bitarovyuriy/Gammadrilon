# План разработки Gammadrilon

Живой документ: что сделано, что дальше, где грабли. Обновляется после каждого
закрытого этапа — чтобы следующая сессия не начинала с нуля.

Правила ведения:

1. В начале работы прочитать разделы **Сейчас** и **Очередь**.
2. Закрыл этап — перенести его в **Сделано** с датой, файлами и проверками,
   обновить **Сейчас** и **Очередь**.
3. Появилась развилка или договорённость с Юрием — записать в **Решения**.
4. Наткнулся на грабли — в **Грабли**, одной строкой: симптом → причина → что делать.
5. Этот файл — про состояние работ. Архитектурные объяснения — в вики, сырой
   дневник — в `V3_PROGRESS.md` (исторический лог, не план).

## Сейчас

- До уточнения зоны IPv6 полный прогон `pytest` с `GD_SMOKE=1` прошёл
  628 тестов. После исправления повторный полный прогон прошёл те же 628
  тестов за 61,56 с, включая offscreen-проверку окна с временным профилем
  и подменой системных записей.
  `ruff check .` и `git diff --check` прошли.
- Готовится предварительный выпуск `v3.6.5` из зафиксированного коммита.
  Пакет включает портативный ZIP, однофайловый EXE, установщик и SHA-256.
  Для публикации нужны успешная самопроверка двух EXE и сверка архива.
  Установка, удаление и обычный запуск GUI на чистой Windows остаются
  в пункте 43. Действующим стабильным выпуском остаётся `v3.6.4`.
- Проверочная сборка PyInstaller onedir открыла восемь страниц через платформу
  Qt `windows`, переключила обе темы и штатно закрылась. Отчёт в
  `build/window-smoke-qa/report.json`. Системные записи в проверке подменены.
- В обеих темах используется монохромная палитра. На минимальном размере
  720×560 проверены главный экран, доступ к горячим клавишам через прокрутку
  и раздел памяти «Утилит». При переходе Tab к нижней кнопке горячих
  клавиш боковое меню прокручивается до неё.
- Выход прерывает ожидание сетевых чтений и загрузок, включая загрузку
  `hosts`. После отправки команды записи интерфейс ждёт ответа помощника.
  При потере соединения результат записи считается неизвестным. Начатые
  изменения системы и откаты дожидаются завершения.
- Перед заменой `hosts` помощник сверяет файл с исходным снимком. Если
  обнаружена внешняя правка, обновление прекращается. Внешний редактор всё
  ещё может изменить файл между последней сверкой и заменой.
- Окно и компаньон координируют запись схемы питания через один именованный
  канал. Прямые вызовы WinAPI и CLI обходят эту синхронизацию. Восстановление
  JSON блокирует запись из других потоков того же процесса. Внешний процесс
  всё ещё может заменить файл между чтением и переносом в `.bak`.
- Стоп-кран приостанавливает новые действия правил и ждёт уже отправленные
  операции перед восстановлением. Автообновление сохраняет копию активного
  конфига и восстанавливает прежние файлы после сбоя проверки новой версии.
  Обновление установленной копии остаётся в пункте 39.
- Остаётся проверить на живой Windows запрос и отмену UAC, применение и откат
  частоты экрана, схемы CPU, лимита мощности GPU и DDC/CI, а также работу
  после сна и сбоя. Обновление установленной копии с реального релиза,
  DNS/DoH, системный `hosts` и обход DPI также требуют проверки.
  Для `hosts` Windows API замены проверен на временных файлах.
  Частичный сбой замены и восстановление имени проверены симуляцией.

## Решения

- Светлая и тёмная темы используют монохромную палитру. Существующие действия
  и разделы сохранены.
- При выходе отменяется ожидание сети. Начатые системные изменения и их откат
  выполняются до завершения.

- **API агентов не возвращать.** Вырезано по прямой просьбе; вкладка, настройка
  и хуки `on_done` удалены. Новые внешние интеграции — только по отдельной просьбе.
- **Сборка — из ASCII-копии** `C:\gd_build` (robocopy перед сборкой). Junction
  не годится: `mklink /J` молча не выполняется, если папка существует, и сборка
  уходит из старой копии.
- **Драйверы и zapret в установщик не входят.** PawnIO и WinDivert ставятся
  отдельно и осознанно: иначе антивирусы блокируют сам установщик.
- **Сертификат подписи не покупаем.** SmartScreen остаётся; это написано в README.
- **Версию поднимать при релизе**, а не после каждой правки: номер живёт только
  в `APP_VERSION`, `tests/test_meta.py` следит за расхождением.
- **Настройки — только в профиле пользователя** (`%LOCALAPPDATA%`), общие файлы
  с компаньоном — в `%ProgramData%`. В ProgramData файл, созданный запуском от
  администратора, обычный запуск перезаписать не сможет: владелец — администраторы,
  у Users только чтение. Запись в ProgramData (`sensors.json`, `gpu_state.json`)
  делает компаньон, UI их только читает.

## Грабли

- Падение при перестройке главной → Qt удаляет дочерний поток вместе с плиткой
  → хранить поток до завершения и привязывать слот результата к жизни плитки.
- Зависшая загрузка при выходе → сокет удерживает ожидающий поток →
  отделить сетевое чтение от записи временного файла и отменять ожидание.
- Smoke зависает в новом временном профиле → открылся диалог первого запуска →
  установить `first_run_done` в настройках тестового профиля.

- **Сборка падает на Qt-плагинах** (`D:/?laude/...`) → кириллица в пути →
  собирать из `C:\gd_build`.
- **`dist` в рабочем репозитории остаётся старым** → собирается копия, а не
  репозиторий → после сборки обновлять `dist` или брать артефакты из `C:\gd_build\dist`.
- **`PermissionError` на `dist\Gammadrilon.exe`** → запущен старый экземпляр →
  закрыть процессы Gammadrilon перед сборкой.
- **Удалённый модуль остаётся в сборочной копии** → `robocopy` без `/MIR` не
  удаляет файлы, вырезанный `gd_agent.py` попадал в сборку → перед сборкой
  запускать `sync_build.ps1` (зеркало, `.venv`/`dist` исключены).
- **Настройки в `%ProgramData%`** → файл, созданный запуском от администратора,
  обычный запуск перезаписать не может (владелец — администраторы) → `presets.json`
  живёт в `%LOCALAPPDATA%`, в ProgramData только обмен с компаньоном.
- **`0xC0000409` (`STATUS_STACK_BUFFER_OVERRUN`)** → необъявленные `argtypes`/`restype`
  обрезают 64-битные указатели до `int`, либо сборщик мусора удалил `WINFUNCTYPE`-колбэк,
  пока WinAPI держал указатель → объявлять сигнатуры явно, колбэк хранить в `self`.
- **`urllib` портит `Request.host`** при проходе через прокси → следующий прямой
  маршрут уходит на адрес мёртвого прокси → клонировать запрос на каждую попытку.
- **i18n-тест требует пары ru↔en** → новый ключ добавлять в оба словаря, иначе
  `test_meta` падает.

## Проверки перед релизом

1. `ruff check .` — чисто.
2. `pytest` — зелёный.
3. `GD_SMOKE=1 pytest tests/test_smoke.py` — окно поднимается.
4. `sync_build.ps1` — зеркало в `C:\gd_build` (`.venv` и `dist` не трогает).
5. `C:\gd_build\build_release.ps1` — exe, zip, Setup.
6. Запустить собранный onedir и onefile, проверить окно.
7. Обновить `dist` в репозитории.
8. Поднять `APP_VERSION`, обновить README/чеклист, проверить `test_meta`.
9. Тег и релиз на GitHub (только через Xray-прокси).
