# Инвентаризация интерфейса Gammadrilon

Карта видимых поверхностей приложения и соответствие снимкам экрана.
Снимки «до» — `screenshots/before/` (35 PNG), «после» — `screenshots/after/`
(39 PNG), текущие — `build/shots/` (там же `report.json` и лог рендера).
Снимки делает `_tmp_shots.py` (offscreen, обе темы; в git скрипт не входит).

## Главное окно

`main.py` → `MainWindow` (QMainWindow). Титлбар с версией и чипом режима,
сайдбар (Питание / Система), контент-вкладки, статусбар с живыми метриками.

Снимки главного окна: `<тема>-<слаг>-window` (окно 910×700 с выбранной вкладкой)
и `<тема>-<слаг>-full` (только контент вкладки, без каркаса окна).

| # | Вкладка (ключ) | Заголовок | Класс страницы | Слаг снимков |
|---|---|---|---|---|
| 1 | `tab.gamma` | Гамма и яркость | страница в `main.py` | `gamma` |
| 2 | `tab.cpu` | Питание процессора | `PowerWindow` | `cpu` |
| 3 | `tab.gpu` | Питание видеокарты | `GpuWidget` | `gpu` |
| 4 | `tab.rules` | Правила | `RulesWidget` | `rules` |
| 5 | `tab.utils` | Утилиты | `UtilsWidget` | `utils` |
| 6 | `tab.dns` | DNS | `DnsWidget` | `dns` |
| 7 | `tab.zapret` | Обход DPI | `ZapretWidget` | `zapret` |
| 8 | `tab.agent` | API агентов | `AgentWidget` | `agent` |

Темы: `dark-…` и `light-…` для каждой вкладки (у `gamma` — только окно,
у остальных — окно + полный контент). Итого 2 × (8 окон + 7 контентов) = 30.

## Оверлеи и меню главного окна (только тёмная тема)

| Снимок | Что это |
|---|---|
| `dark-tray-menu` | контекстное меню трея |
| `dark-overlay-toast-ok` | тост-подтверждение (монохром, серая полоса слева) |
| `dark-overlay-toast-error` | тост-ошибка (пунктирная рамка) |

## Панели-оверлеи главного окна (диалоги)

| Снимок | Класс | Роль |
|---|---|---|
| `dark-dialog-onboarding` | `FirstRunDialog` (`gd_onboarding.py`) | знакомство при первом запуске |
| `dark-dialog-palette` | `CommandPalette` (`gd_palette.py`) | палитра команд (Ctrl+Alt+G), пустое состояние «Ничего не найдено» |
| `dark-dialog-journal` | `JournalDialog` (`gd_journal_ui.py`) | журнал изменений |
| `dark-dialog-rule` | `RuleDialog` (`gd_rules_ui.py`) | создание/правка правила |
| `dark-dialog-processpicker` | `ProcessPicker` (`gd_utils_ui.py`) | выбор процессов для сжатия рабочих наборов |
| `dark-dialog-reset-confirm` | `ConfirmDialog` (`gd_dialog.py`) | подтверждение сброса (destructive — пунктир) |

Ещё в приложении: `MessageDialog`/`ConfirmDialog` (`gd_dialog.py`) — все
информационные окна и подтверждения; `AgentConfirmDialog` (`gd_agent_ui.py`) —
подтверждение действия агента (снимок живёт в контексте вкладки `agent`);
`HotkeySettingsDialog` (`main.py`) — настройка горячих клавиш, открывается из
сайдбара; системный `QInputDialog` для имени пресета и клавиши (наследует
общий QSS, отдельного снимка нет).

## Вне главного окна (в снимки не входят)

- Отдельные процессы с самостоятельным окном: `gd_power_ui.py`, `gd_gpu_ui.py`
  (standalone-режимы для отладки; в приложении живут как вкладки).
- Трей: иконка и всплывающие подсказки ОС.

## Легенда состояний на снимках

Кнопки — `hover` / `pressed` / `focused` / `disabled`; сегменты и чипы —
`selected`; вкладки сайдбара — активная подложка + белая полоса слева;
таблицы — выделение строки фоном с акцентным подчёркиванием (сетка скрыта);
пустые состояния — текстом («Правил пока нет», «Ничего не найдено — измени
запрос», «Процессов не нашлось»).
