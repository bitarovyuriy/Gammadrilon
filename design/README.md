## Монохром A — палитра

- Фон `#000000`, поверхности `#0B0B0B` / `#141414`, линии `#1F1F1F` / `#2E2E2E`.
- Текст: `#F5F5F5` / `#C4C4C4` / `#8A8A8A`; акцент — чистый белый `#FFFFFF`.
- Активные элементы — инверсия: белый фон + чёрный текст (чипы профилей, primary-кнопки, сегменты).
- Активный пункт сайдбара: серая подложка + белая полоса-маркер слева.
- Градиент гаммы обесцвечен (`#5A5A5A → #E8E8E8`); destructive-кнопки — пунктирная рамка вместо красного.
- Проверено пиксельно: **0 цветных пикселей** из 1 016 784 (скрипт `mono_check.py`).

## Общее для всех вариантов

- Горизонтальные вкладки сверху убраны как основной паттерн.
- Живые метрики — крупно и с tabular-nums; единицы всегда подписаны.
- Статусы — пилюлями и точками, а не мелким текстом.
- Всё переносимо в PyQt5/QSS: рамки, скругления, цвета, отступы, простые тени.
