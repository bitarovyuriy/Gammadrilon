# Gammadrilon 3.6.5 — предварительный выпуск

Обновлены интерфейс, завершение фоновых операций и восстановление системных настроек. Этот выпуск предназначен для проверки на Windows перед стабильным релизом.

## Что изменилось

- Светлая и тёмная темы используют монохромную палитру. Улучшены компоновка главного экрана и «Утилит» в узком окне, доступ к горячим клавишам и видимость результатов действий.
- Закрытие окна прерывает ожидание сетевых загрузок. Если системная запись уже началась, приложение дожидается результата. Оборванная загрузка оставляет прежний файл.
- Перед изменением лимита мощности GPU помощник сохраняет исходное значение и UUID карты. NVML и резервный вызов `nvidia-smi` используют тот же UUID. При неизвестном результате исходный снимок остаётся для повторного восстановления. Для старых снимков без UUID в README описано ручное восстановление.
- Откат схемы питания и временной частоты экрана сохраняет данные, нужные для повтора после сбоя. Общий помощник GPU и zapret сообщает результат отката перед выходом.
- Восстановление DNS и DoH учитывает GUID сетевого адаптера и параметры IPv4 и IPv6. При частичном сбое приложение сохраняет данные, которые ещё нужны для отката. Для старого IPv4-снимка требуется подтверждение выбранного адаптера.
- При обновлении `hosts` резервная копия и новый файл строятся из одного снимка. Перед заменой приложение проверяет, не изменился ли файл с момента чтения.
- Обновление приложения сохраняет копию активных настроек. При ошибке проверки новой версии скрипт обновления пытается вернуть прежние файлы и настройки.

## Файлы выпуска

- `Gammadrilon-Setup-3.6.5.exe` — установщик Windows x64.
- `Gammadrilon.exe` — однофайловая сборка.
- `Gammadrilon-portable.zip` — портативная папка. Распакуйте ZIP перед запуском.
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

## Что ещё предстоит проверить

Установка и удаление на чистой Windows, обычный запуск собранных EXE и обновление поверх установленной версии требуют отдельного прогона. На реальном оборудовании остаётся проверить запрос и отмену UAC, применение и откат CPU/GPU/DDC, переключение частоты, DNS/DoH, системный `hosts`, zapret и восстановление после сна или сбоя.
